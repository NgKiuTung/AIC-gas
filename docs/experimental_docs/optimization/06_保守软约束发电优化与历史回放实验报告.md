# 保守软约束发电优化与历史回放实验报告

## 1. 实验目标与数据边界

本实验在预测阶段结束后，建立未来 2 小时、15 分钟粒度的滚动发电调度基线。优化必须同时满足：

1. 不使用评分测试集；
2. 只使用预测起点及之前已知的煤气配比和气柜状态；
3. 使用严格时间顺序 OOF 预测作为未来资源边界；
4. 官方气柜、容量和爬坡硬约束零违规；
5. 不虚构初赛数据中没有提供的启动成本、最小开停时间和完整气柜流量；
6. 优化前后窗口总发电能量及三类煤气总量守恒；
7. 经济改善需跨时间折稳定，而不是由少量案例驱动。

**本实验未读取、检查、转换或使用“初赛-评分所用测试集”。**

## 2. 优化方法

### 2.1 决策变量

每个 2 小时窗口含 8 个时刻，主要决策变量包括：

- 4 台 50MW 机组聚合负荷；
- 2 台 120MW 机组聚合负荷；
- 两组在线机组台数；
- 相对预测基线的负荷偏差；
- 相邻时刻负荷变化；
- 正常最小负荷过渡松弛；
- 经验平滑变化超限松弛。

求解器使用 `scipy.optimize.milp` 的 HiGHS 混合整数规划实现。

### 2.2 目标函数

优化目标为：

`最大化分时电价替代外购电收益 - 计划偏离惩罚 - 波动惩罚 - 过渡松弛惩罚`

其中电价直接来自官方 `price.xlsx`。能量松弛在最终版本被固定为 0，因此优化器不能通过“凭空增加发电量”提高收益。

### 2.3 官方硬约束

- 高炉煤气柜：30,000–180,000 m³；
- 50MW 机组组容量：0–200 MW；
- 120MW 机组组容量：0–240 MW；
- 开机状态正常负荷：单机额定容量的 60%–100%；
- 官方爬坡：额定容量的 10%/分钟；
- 优化窗口内预测资源总能量守恒。

官方爬坡换算到 15 分钟后大于机组完整容量区间，因此在本粒度下天然不约束；模型另使用更严格的经验变化偏好并对超出部分单独记录。

### 2.4 正常负荷过渡松弛

初赛数据只有聚合负荷，没有单机启停状态。历史上约 11% 时刻无法严格映射到单机 60%–100% 的可行区间，说明数据中包含启动、停机、短时过渡或聚合计量偏差。

首轮实验把 60% 下限设为所有时刻硬约束，造成个别窗口能量松弛最高 11.75%，不可接受。最终版本改为：

- 在线台数和最大容量保持硬约束；
- 低于正常最小负荷的部分使用高惩罚、显式输出的过渡松弛；
- 总能量保持硬等式，不允许用能量松弛掩盖启停信息缺失。

最终均衡方案的过渡时刻比例为 1.03%，显著低于历史不可辨识比例，且所有松弛均在结果表逐时保留。

### 2.5 相对气柜模型

由于初赛字段无法形成完整气柜质量守恒，模型不把低质量经验回归当成硬物理关系。采用相对基线方法：

`优化柜容 = 起点柜容 - 累计（优化高炉煤气用量 - 基线高炉煤气用量）`

预测基线下未知的外部产气、生产用户和其他管网流量在差分中抵消。该方法只评估调度变化新增的气柜风险，不声称重建了完整厂级煤气平衡。

### 2.6 三类煤气输出

每个窗口使用预测起点已经观测到的三类“发电煤气量/总负荷”比例，并裁剪到训练期 5%–95% 分位区间。优化后输出：

- `opt_generator_use_blast_furnace_gas`；
- `opt_generator_use_coke_gas`；
- `opt_generator_use_converter_gas`。

由于窗口总负荷能量严格守恒且窗口内配比固定，三类煤气总量也严格守恒。

## 3. 回放协议

- 未来边界：严格三折时间 OOF 预测；
- 优化窗口：8×15 分钟；
- 采样：每 2 小时一个非重叠起点；
- 初始候选：534 个完整窗口；
- 有效窗口：532 个；
- 排除 1 个起点气柜原本低于官方安全下限的窗口；
- 排除 1 个时间缺口造成非有限输入的窗口；
- 评分测试数据访问：否。

经济主指标为相对同一 OOF 预测资源边界的收益提升，避免把预测能量误差误算为优化收益。相对历史实际收益仅保留为辅助字段，不作为方案选择依据。

## 4. 参数敏感性

| 方案 | 有效窗口求解成功率 | 变价窗口平均收益提升 | 平均绝对调度变化 | 过渡时刻比例 | 内部气柜裕度 |
|---|---:|---:|---:|---:|---:|
| 保守 | 100% | 2.2648% | 7.33 MW | 1.79% | 5,000 m³ |
| 均衡 | 100% | **3.2159%** | 11.03 MW | 1.03% | 5,000 m³ |
| 激进 | 100% | 4.0478% | 13.09 MW | 0.16% | 0 m³ |

激进方案收益最高，但没有内部气柜安全裕度，且调度变化最大。最终选择均衡方案：它保留 5,000 m³ 内部裕度，同时获得激进方案大部分收益。

## 5. 均衡方案验收结果

| 验收项 | 结果 | 是否通过 |
|---|---:|---:|
| 有效窗口求解成功率 | 100% | 是 |
| 官方气柜/容量/爬坡违规 | 0 | 是 |
| 最大能量松弛 | 0 | 是 |
| 能量与三类煤气最大相对守恒误差 | 1.92×10⁻¹⁴ | 是 |
| 变价窗口平均收益提升 | 3.2159% | 是 |
| 4,000 次 bootstrap 95% CI | 2.8985%–3.5400% | 是 |
| 三个时间折平均收益提升 | 全部为正 | 是 |
| 过渡时刻比例 | 1.0338% | 是 |
| 综合验收 | — | **通过** |

按时间折拆分，变价窗口平均收益提升分别为：

- fold 1：4.4354%；
- fold 2：3.0120%；
- fold 3：2.1838%。

收益随时间段下降，说明电价切换结构、预测误差或可调空间存在时间漂移，但三个时间折均保持正值。

### 6.1 典型窗口、安全轨迹与策略权衡

![优化调度总览](../../../results/visualizations/optimization/optimization_dispatch_overview.png)

典型窗口按“变价窗口中最接近中位收益提升”自动选择，不是人工挑选最佳案例。图中可以直接观察到：电价下降前提高发电负荷、下降后降低负荷；累计增量用气导致的柜容轨迹始终处于安全带内；均衡方案位于收益和调度幅度之间。

### 6.2 折间稳定性

![优化折间稳定性](../../../results/visualizations/optimization/optimization_fold_stability.png)

三个按时间顺序划分的验证折收益均为正，但 fold 3 的改善较小，因此未来部署需要滚动更新预测和优化参数，不能假定收益恒定。

### 6.3 收益分布与电价切换

![优化收益分布](../../../results/visualizations/optimization/optimization_uplift_distribution.png)

收益主要来自包含电价切换的窗口。电价不变化的窗口中，由于总能量守恒，收益中位数接近 0，这是合理结果而非模型失效。

## 7. 局限与后续升级

1. 当前收益是相对 OOF 预测基线的计划收益，不是已经在真实工厂执行后的因果收益。
2. bootstrap 以两小时窗口为重采样单位，没有完全消除相邻工业时序的依赖。
3. 相对气柜模型只能检查调度变化的增量风险；后续获得完整煤气流量后，应升级为完整质量守恒。
4. 初赛没有单机状态、启动成本和最小开停时间，当前过渡松弛必须在后续数据中重新标定。
5. 初赛正式评分只包含预处理和短周期预测，本优化结果属于后续赛段的可审计预研基线。
