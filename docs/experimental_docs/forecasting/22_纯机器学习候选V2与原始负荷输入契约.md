# 纯机器学习候选V2与原始负荷输入契约

日期：2026-09-05。范围：初赛训练数据，评分目录与桌面提交文件未访问或修改。

## 变更

新增独立GPU LightGBM候选。当前原始负荷generator_1和generator_all作为明确的输入字段纳入训练矩阵；缺失时采用既有因果填充，并保留已有缺失标记。未来标签仍由原始观测按时间戳关联，未使用填充目标训练。这一变更是输入契约表达完善，并不证明旧版遗漏原始名称造成官方扣分，也不保证增加重复当前负荷列提高精度。

删除名字含converter_balance_proxy的特征，避免把缺少单位换算依据的差值作为物理平衡解释；加入8路信号的过去96点FFT/Haar特征。保留旧字段副本使候选能完整追踪历史特征来源。

输入验证器增加合法的当前负荷原始字段，继续拒绝future prediction列和未知原始字段。旧801字段输入仍可使用；不改变官方要求尚未明确的全空列政策。

## 训练与复现

LightGBM GPU预检通过。首次沙箱预检无法写入OpenCL缓存，经授权在沙箱外运行成功。候选使用GPU、L1目标、120轮、31叶、学习率0.03、L1正则1、L2正则20、特征采样0.7、种子20260905。每个目标和步长单独训练绝对残差模型，最后叠加当前负荷，并实施非负和总量不低于部分量的约束。该候选不是既有4.6306%嵌套候选的精确复刻，禁止直接继承旧候选成绩。

回顾性窗口为4月1–2、15–16、22–23日，训练标签时刻严格早于每个窗口开始。此前研究已经使用这些日期，因此不能称为独立留出集。另训练全量历史候选包；训练数据截断至5月1日之前，完整训练重放仅检查可读、重载和打包，不计算训练内MAPE冒充验证。

每个模型文件重载后的预测需与保存前在1e-8容差内一致。每个窗口输出诊断用双CSV ZIP，验证字段、时序和内容完整性。特征前缀检查包括频域描述。全量候选没有生成评分期预测，也没有晋级为正式提交。

分目标：generator_1由5.5297%降至5.3414%，generator_all由3.1205%降至3.1059%。120分钟步长由6.4419%降至6.1413%，长步长仍是主要优化对象。上述窗口已经用于研究，不作为未触碰留出集；9216个误差项存在时间重叠，不能当成9216个独立样本推断显著性。不能将4.2237%直接宣称为平台总分95.7763分，初赛还包含预处理评分。
