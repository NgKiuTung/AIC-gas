# 数据清洗再审计与预测优化实验报告

## 1. 实验目的与数据边界

本轮实验从原始训练数据重新检查时间完整性、缺失值、异常点和已有清洗流程，随后围绕短周期（未来 15 至 120 分钟）发电负荷预测开展特征与模型迭代。所有统计、特征构造、模型训练和交叉验证均仅使用 `dataset/初赛-数据集` 中的训练数据。

**未读取、未检查、未转换、未训练 `dataset/初赛-评分所用测试集`。** 所有实验摘要中的 `external_scoring_data_accessed` 均为 `false`。

## 2. 清洗再审计

### 2.1 时间与缺失

- 四张训练表合并后的原始时间轴共有 11,519 个 15 分钟时刻、29 个业务字段。
- 全局缺失时刻为 2025-01-01 03:00、2025-04-28 18:00 和 2025-04-28 18:15。
- 已有预处理仅补充缺失时刻和原始空值，共填补 97 个单元格；没有改写任何原本非空的观测值。
- 时间缺口采用训练集内、局部时间邻域的拉格朗日插值候选，并通过人为遮挡验证选择方法；因果版数据另保留只依赖历史的填补结果，供预测特征构造使用。

### 2.2 全空列

结合 `data_dictionary.xlsx` 核对后，全空列不是必然需要“预测补齐”的标签，而是当前数据段中没有有效观测的设备/字段。强行用其他列回归重建会制造不可验证的伪观测。因此：

- 原始层保留字段及其空值状态，保证字段血缘完整；
- 建模层不把全空原值直接作为数值特征；
- 若存在业务上可解释的同类汇总量，只构造明确命名的代理特征，不覆盖原列；
- 不把模型估计值伪装成赛事原始观测。

### 2.3 异常值判断

- `generator_1 <= generator_all` 的层级约束违反次数为 0，两个预测目标也均无零值。
- 对负荷大跳变点检查前后持续性后发现，多数为连续运行工况切换，而非孤立传感器尖刺。
- 因此本轮不对原始非空负荷做削峰、截尾或平滑替换，只额外提供平滑视图、跳变强度、状态与异常标志作为模型输入。

该策略避免了把真实启停和负荷切换当成脏数据删除。

## 3. 清洗增强特征

在原有严格因果特征基础上新增 309 个特征，总计 869 个：

| 特征组 | 数量 | 作用 |
|---|---:|---|
| transition | 117 | 多尺度跳变、趋势、工况切换 |
| smooth | 90 | 因果 EWM/局部平滑视图及原值偏差 |
| state | 52 | 当前运行水平和离散工况描述 |
| clean_view | 25 | 不覆盖原值的稳健清洗视图 |
| change_state | 12 | 变化方向与变化幅度状态 |
| mechanism_ratio | 9 | 煤气产耗、发电用气与柜位的机理比值 |
| quality | 4 | 缺失、插值、异常质量标志 |

特征重要性汇总显示，rolling、lag、smooth、base、transition 五组累计贡献约 85.9%。最重要的单项包括气柜平滑偏差、120MW 组长期平滑偏差、气柜差分、短期负荷滞后以及高炉煤气发电用气占供给比例。这说明气柜动态、机组惯性和工况切换确实是主要信号。

组消融后保留 801 个有效特征组；已知未来分时电价另形成 74 个严格确定性的未来特征，但验证结果未提升，故不纳入当前最优方案。

## 4. 验证设计

- 使用严格时间顺序的 3 折滚动验证，不随机打乱。
- 每个预测起点只使用该时刻及之前的特征。
- 同时预测 `generator_1` 与 `generator_all` 的未来 8 个 15 分钟步长。
- 主指标为所有目标、步长和验证样本的 MAPE；同时与“当前值保持不变”的 persistence 基线比较。
- GPU 模型使用 RTX 4060 上的 XGBoost CUDA 实现。

## 5. 迭代结果

| 方案 | 验证 MAPE | 结论 |
|---|---:|---|
| 原最终混合模型 | 5.5528% | 本轮起点 |
| 清洗增强 d5 混合目标 | 5.5036% | 有效提升 |
| 原模型/清洗增强 OOF 集成 | 5.5017% | 小幅提升 |
| 清洗特征组消融 | 5.4975% | 删除弱特征有效 |
| d6 正则化容量扩展 | 5.4958% | 单模型继续小幅改善 |
| 动态修正门控 | 5.4735% | 对工况切换更稳健 |
| 多深度集成 + 动态门控 | **5.4671%** | 当前最优 |
| 已知未来电价路径 | 5.5087% | 未提升，拒绝 |
| MAPE 对齐加权目标 | 5.7641% | 明显退化，拒绝 |
| 因果 TCN 序列模型 | 5.7597% | 明显退化，拒绝 |
| 机组 1 工况分类辅助 | 未超过 5.4671% | 分类准确率约 61.3%，拒绝 |

当前最优相对 persistence 的 5.8050% MAPE 降低约 5.82%，对应验证得分 `1-MAPE = 0.945329`。

当前目标拆分结果：

- `generator_1`：6.2587%；采用 d6 模型和较保守的动态门控。
- `generator_all`：4.6755%；采用 d5/d6 各 50% 集成和更积极的动态修正。

## 6. 最优方案参数与解释

### generator_1

- 模型权重：d6 = 1.0；
- 工况门控阈值：0.08；
- 门控下限：0.75；
- 修正系数从 15 分钟的 0.55 线性过渡到 120 分钟的 0.45。

### generator_all

- 模型权重：d5 = 0.5，d6 = 0.5；
- 工况门控阈值：0.08；
- 门控下限：0.25；
- 修正系数从 15 分钟的 1.00 线性过渡到 120 分钟的 0.80。

`generator_1` 的误差更高，主要原因是其聚合了 4 台 50MW 机组，但数据只提供汇总负荷，无法直接观察单机启停状态。工况分类实验的验证准确率不足以稳定恢复隐含启停组合，因此没有把不可靠的类别判断强行加入最终预测。

## 7. 关于 5% 目标的结论

本轮没有在严格训练集滚动验证下把总体 MAPE 压到 5% 内。当前 5.4671% 是已验证候选中的最好结果，但不能声称是理论最优，也不能以同一 OOF 上继续反复调参得到的偶然低值冒充稳定泛化性能。

进一步提升更可能依赖：

1. 官方后续数据中提供可观测的单机启停或生产计划字段；
2. 更长历史覆盖更多机组切换模式；
3. 用独立时间留出段重新选择门控和集成参数；
4. 对煤气发生量、生产用户需求和可用于发电煤气量做联合概率预测。

在现有初赛训练信息下，继续堆叠同类模型的边际收益已经很低。因此后续转入发电计划优化环节，不再为追求表面上的 5% 阈值而引入测试数据、未来泄露或过度清洗。

### 9.1 总体误差、时段和特征证据

![预测总体诊断](../../../results/visualizations/prediction/prediction_oof_overview.png)

图中显示：

- 两个目标的误差均随预测步长增加；

![预测典型日曲线](../../../results/visualizations/prediction/prediction_representative_day.png)

案例不是人工挑选的最好或最差日期，而是在 120 分钟预测中，自动选择最接近完整日误差中位数的日期。可以看到，模型对平稳区间拟合较好，但在突发负荷阶跃处仍存在滞后，这与工况切换是当前主要误差来源的判断一致。
