# 初赛官方要求对齐矩阵

本矩阵以 `docs/competition/official/煤气发电量预测与发电优化-2.pdf` 为唯一官方基线之一。平台最新公告或模板如与 PDF 冲突，以平台最新要求为准并记录变更。

| PDF 位置 | 官方要求 | 当前整改验收 |
|---|---|---|
| 第 2、8 页 | 预测只能使用参考时刻及之前的数据，禁止未来信息和测试标签泄露 | 训练策略与提交策略隔离；因果不变性测试通过 |
| 第 3–4 页 | 初赛训练期为 2025-01-01 至 2025-04-30，评分期为 2025-05-01 至 2025-05-02；CSV 为 UTF-8，时间戳格式固定 | 时间边界、编码和时间格式纳入数据契约 |
| 第 4 页 | 自行处理缺失、重复、异常、多表时序对齐 | 对抗性预处理测试覆盖缺失、重复、乱序、断档、异常和全空列 |
| 第 5 页 | 核心预测指标为 1-MAPE | 同时报告 post-selection OOF 与嵌套时间外层评估，不混淆统计口径 |
| 第 6 页 | 全量测试推理原则上不超过 30 分钟；Python 3.8–3.10；应提供 requirements.txt、README 和运行脚本；GPU 非强制 | Python 3.10 干净环境、精确依赖、CPU 推理和运行时基准通过 |
| 第 7 页 | 初赛数据预处理 50%，短周期预测 50% | 冻结优化开发，优先完成预处理复现与两小时预测提交链 |
| 第 7–8 页 | 建议 15 分钟采样、时间顺序验证和滚动预测；严禁参考时刻之后的数据 | 统一 15 分钟、嵌套时序验证、滚动因果特征构造 |
| 第 8 页 | 禁止传播、转售、公开展示或泄露赛事数据 | 仓库 Private；Git/Release 不含原始、逐行或可恢复真实时序数据 |
| 第 9 页 | 初赛短周期预测为 15–120 分钟；字段采用 `generator_*_t+XX_pred`；不得缺行或重复 | SubmissionAdapter 和 SubmissionValidator 精确检查 17 列 |
| 第 9–10 页 | 后期滚动起点仍需完整输出；CSV UTF-8；预测至少保留三位小数 | 全起点覆盖、有限值、唯一时间戳和精度检查 |
| 第 10 页 | 初赛 ZIP 内仅一个 `result.csv`，压缩包名为 `teamname_gas_predict_prelim.zip` | 打包器验证 ZIP 成员数、文件名和可解压性 |

## 执行边界

- 当前阶段不得读取或枚举评分测试集。
- 提交链先在合成原始表上完成端到端验证。
- 在真实评分推理前必须再次获得用户明确授权；该进程只读输入、不执行训练、调参或指标计算。
- 所有整改报告保存于 `docs/compliance/`，所有检查结果保存于 `results/compliance/`。
