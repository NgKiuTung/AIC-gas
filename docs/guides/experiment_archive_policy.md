# 实验归档策略

实验存档和实验报告属于项目受保护资产，不允许为了整理目录、减小 Git 仓库或开展新实验而删除、覆盖旧版本。

每个里程碑版本必须保存：

1. `docs/experimental_docs/` 中的全部实验报告及实验索引。
2. `results/` 中除历史 `releases/` 和可能包含提交预测的 `submissions/` 外的全部产物，包括预处理审计、特征缓存、实验指标、逐行结果、模型、日志、优化结果、图表和验证记录。
3. 完整文件级清单，记录相对路径、字节数和 SHA-256。
4. 压缩归档包自身的 SHA-256，以及与版本对应的 Git 提交和标签。

完整实验包保存在 `results/releases/<version>/artifacts/full_experiment_archive.zip`。整个 `results/releases/` 必须被 Git 忽略，也不得作为 GitHub Release 公开发布；跨机器备份只能使用访问受控且符合赛事规则的私有存储。评分集和原始数据目录禁止进入归档。

版本快照采用只增不改策略：同名版本存在时，创建脚本必须失败。需要补充资料时应提升版本号，不得修改旧快照。
