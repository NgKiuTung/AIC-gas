二、新增特征详情（102个）
================================================================================

A. 未来价格特征（80个）

   为什么重要？
   - 电价是提前公布的，未来2小时的价格是已知信息
   - 允许模型做策略性决策，而非被动反应
   - 这是最大的改进机会！

   特征列表：
   1) 基础未来价格（8个）
      feat_future_price_h1 到 h8

   2) 价格变化（16个）
      feat_future_price_delta_h{1-8}         # 绝对变化
      feat_future_price_pct_change_h{1-8}    # 百分比变化

   3) 方向指标（16个）
      feat_future_price_up_h{1-8}            # 上涨标记
      feat_future_price_down_h{1-8}          # 下跌标记

   4) 路径统计（32个）
      feat_future_price_path_mean_h{1-8}     # 路径均值
      feat_future_price_path_max_h{1-8}      # 路径最大
      feat_future_price_path_min_h{1-8}      # 路径最小
      feat_future_price_path_range_h{1-8}    # 路径范围

   5) 全局特征（8个）
      feat_future_price_max_all              # 最高价格
      feat_future_price_min_all              # 最低价格
      feat_future_price_range_all            # 价格区间
      feat_future_price_mean_all             # 平均价格
      feat_future_price_trend_h1_h4          # 前半段趋势
      feat_future_price_trend_h4_h8          # 后半段趋势
      feat_future_price_change_count         # 变化次数
      feat_future_price_steps_to_change      # 到变化的步数

B. 交互特征（22个）

   为什么重要？
   - 捕获非线性关系
   - 例如："高价格"的效果取决于"储气柜水平"
   - 线性模型无法学到这种组合效应

   特征列表：
   1) 价格交互（10个）
      feat_interact_price_holder             # 价格 × 储气柜
      feat_interact_price_p50                # 价格 × P50功率
      feat_interact_price_pall               # 价格 × 总功率
      feat_interact_price_bfg_balance        # 价格 × 气体平衡
      feat_interact_price_change_h4_holder   # 未来价格变化 × 储气柜
      feat_interact_price_trend_h1_h4_pall   # 价格趋势 × 总功率
      feat_interact_price_price_level        # 价格 × 价格等级
      feat_interact_price_holder_weekend     # 三阶：价格×储气×周末
      feat_interact_price_balance_peak       # 三阶：价格×平衡×高峰

   2) 时间交互（5个）
      feat_interact_weekend_hour             # 周末 × 小时
      feat_interact_weekend_peak             # 周末 × 高峰
      feat_interact_weekend_price_level      # 周末 × 价格等级
      feat_interact_month_hour               # 月份 × 小时

   3) 气体系统交互（5个）
      feat_interact_bfg_balance_p50          # 气体平衡 × P50
      feat_interact_bfg_balance_pall         # 气体平衡 × 总功率
      feat_interact_holder_gen_bfg           # 储气柜 × 用气量
      feat_interact_bf_supply_ah_use         # 高炉 × 热风炉
      feat_interact_holder_bf_supply         # 储气柜 × 高炉产气

   4) 状态质量交互（4个）
      feat_interact_total_zero_states        # 零状态总数
      feat_interact_critical_zero            # 关键零状态
      feat_interact_zero_states_pall         # 零状态 × 功率
      feat_interact_outlier_pall             # 异常值 × 功率

================================================================================
三、关键价值说明
================================================================================

1. 未来价格的价值（实例）

   场景：当前10:00，预测10:15-12:00的发电功率

   没有未来价格特征：
   - 模型只看到：当前价格 = 0.5元
   - 模型决策：低价格，减少发电
   - 问题：11:00价格会涨到1.2元（高价），但模型不知道！

   有未来价格特征：
   - 模型看到：当前0.5元，h4(11:00)会到1.2元
   - 模型看到：未来价格会+140%
   - 模型决策：现在存气，11:00全力发电赚取高收益
   - 结果：策略性优化，而非被动反应

2. 交互特征的价值（实例）

   场景：高价格时应该多发电吗？

   没有交互特征：
   - 模型看到：价格=1.2（高），储气柜=85000（高）
   - 模型线性思考：高价+高储气 = 各自贡献权重
   - 预测：90 MW

   有交互特征：
   - 模型看到：price_holder_interaction = 1.02（超高值）
   - 模型理解：高价格 AND 充足气体 = 触发全力发电模式
   - 预测：120 MW（更准确）

   对比场景：高价格 + 低储气
   - price_holder_interaction = 0.30（低值）
   - 模型理解：虽然价格高，但气不够，受限运行
   - 预测：60 MW

   关键：交互特征提供了3.4倍的信号对比，这在没有交互时是不可见的！
