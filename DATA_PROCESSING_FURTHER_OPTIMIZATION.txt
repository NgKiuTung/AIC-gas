## 优化1：异常值检测与修正（重要性：⭐⭐⭐⭐）

### 问题：
当前没有明确的异常值检测，可能存在：
- 传感器故障
- 数据录入错误
- 突发异常事件

### 建议方法：

A. 基于物理规则的异常检测
```python
# 发电功率不能超过容量
generator_1 > 120 MW → 异常
generator_all > 200 MW → 异常

# 储气柜不能为负或超容
holder < 0 or holder > 100000 → 异常

# 发电总功率必须 >= 单机功率
generator_all < generator_1 → 异常
```

B. 基于变化率的异常检测
```python
# 15分钟变化不应超过30%（正常运行）
change_rate = abs((t - t-1) / t-1)
if change_rate > 0.3:
    可能异常
```

C. 基于统计的异常检测
```python
# 滑动窗口 + IQR方法
window = 96  # 1天
Q1, Q3 = rolling_quantile(window)
IQR = Q3 - Q1
outliers = (x < Q1 - 3*IQR) | (x > Q3 + 3*IQR)
```

### 实施策略：
1. 识别异常值
2. 对异常值打标记（作为特征）
3. 修正异常值（插值或限制）

预期改进：0.05-0.15pp

## 优化2：数据平滑与去噪（重要性：⭐⭐⭐）

### 问题：
15分钟采样数据可能有高频噪声，影响预测稳定性。

### 建议方法：

A. 指数平滑（EMA）
```python
# 对关键变量应用
generator_1_smooth = EMA(generator_1, span=4)
holder_smooth = EMA(holder, span=8)
```

优势：
- 去除噪声
- 保留趋势
- 简单高效

B. Savitzky-Golay滤波
```python
from scipy.signal import savgol_filter
# 多项式拟合平滑
generator_1_sg = savgol_filter(generator_1, window=11, polyorder=3)
```

优势：
- 保留峰值特征
- 去除高频噪声
- 适合时间序列

### 实施策略：
1. 对关键变量（generator_1, generator_all, holder）应用平滑
2. 同时保留原始值和平滑值作为特征
3. 让模型选择使用哪个

预期改进：0.03-0.08pp

## 优化3：标签平滑（Label Smoothing）（重要性：⭐⭐⭐⭐）

### 问题：
当前直接预测原始标签，但标签可能有噪声。

### 建议方法：

A. 对标签应用轻微平滑
```python
# 不是平滑特征，而是平滑要预测的标签
label_smoothed = 0.9 * label_raw + 0.1 * label_moving_average

# 或者用多步平均
label_h1 = average(raw_h1, raw_h2)  # 轻微向后看
```

B. 对极端标签值进行Winsorize
```python
# 限制标签在合理范围
label_clipped = clip(label, percentile_1, percentile_99)
```

### 实施策略：
1. 对训练标签应用轻微平滑（但不改变测试预测）
2. 降低模型对噪声的过拟合

预期改进：0.03-0.10pp

## 优化4：时间窗口特定的标准化（重要性：⭐⭐⭐）

### 问题：
不同时间段数据分布不同（Fold1 vs Fold3差异大）

### 建议方法：

A. 滚动窗口标准化
```python
# 使用最近N天的均值和标准差标准化
window = 7 * 96  # 7天
rolling_mean = df.rolling(window).mean()
rolling_std = df.rolling(window).std()

normalized = (df - rolling_mean) / rolling_std
```

B. 分时段标准化
```python
# 不同时段（白天/夜间）分别标准化
day_mask = (hour >= 8) & (hour < 20)
df[day_mask] = (df[day_mask] - day_mean) / day_std
df[~day_mask] = (df[~day_mask] - night_mean) / night_std
```

### 实施策略：
1. 对高方差特征应用滚动标准化
2. 让模型学到的是相对变化而非绝对值

预期改进：0.05-0.12pp

## 优化5：特征缩放优化（重要性：⭐⭐）

### 问题：
XGBoost对特征尺度不敏感，但极端值可能影响分裂。

### 建议方法：

A. RobustScaler（对异常值鲁棒）
```python
from sklearn.preprocessing import RobustScaler
# 使用中位数和IQR缩放，对异常值不敏感
scaler = RobustScaler()
scaled = scaler.fit_transform(features)
```

B. QuantileTransformer（转为均匀分布）
```python
from sklearn.preprocessing import QuantileTransformer
# 转换为均匀或正态分布
transformer = QuantileTransformer(output_distribution='uniform')
```

### 实施策略：
1. 只对高偏度特征应用
2. 测试是否改进

预期改进：0.02-0.05pp

## 优化6：数据增强（Data Augmentation）（重要性：⭐⭐）

### 问题：
训练数据只有120天，可能不够充分。

### 建议方法：

A. 时间扰动
```python
# 轻微时间偏移（±1步）
augmented_data = []
for offset in [-1, 0, 1]:
    shifted = df.shift(offset)
    augmented_data.append(shifted)
```

B. 噪声注入（训练时）
```python
# 添加小噪声提高鲁棒性
noise_level = 0.01
augmented = features + noise_level * features.std() * np.random.randn()
```

### 实施策略：
1. 只在训练时使用
2. 增加样本多样性

预期改进：0.02-0.05pp

## 优化7：目标变换（Target Transformation）（重要性：⭐⭐⭐）

### 问题：
当前直接预测功率值，但分布可能不是最优的。

### 建议方法：

A. 预测变化量而非绝对值
```python
# 当前：预测 y_t+h
# 改为：预测 delta = y_t+h - y_t
# 训练：model.fit(X, delta)
# 预测：y_pred = y_current + model.predict(X)
```

优势：
- 变化量更稳定
- 趋势更明显
- MAPE可能降低

B. 预测相对变化
```python
# 预测 relative_change = (y_t+h - y_t) / y_t
# y_pred = y_current * (1 + model.predict(X))
```

C. 对数变换
```python
# 对偏态分布有效
log_y = log1p(y)
# 训练后反变换
y_pred = expm1(model.predict(X))
```

### 实施策略：
1. 测试变化量预测
2. 如果效果好，正式使用

预期改进：0.05-0.15pp

## 优化8：样本权重（Sample Weighting）（重要性：⭐⭐⭐）

### 问题：
所有样本等权重，但有些时刻更重要。

### 建议方法：

A. 根据误差加权
```python
# 历史预测误差大的时刻，加大权重
weights = 1 + abs(historical_error)
model.fit(X, y, sample_weight=weights)
```

B. 根据时间加权
```python
# 近期数据权重更高
days_ago = (max_date - date).days
weights = exp(-decay_rate * days_ago)
```

C. 根据价格加权
```python
# 高价时段预测更重要（收益更大）
weights = price / price.mean()
```

### 实施策略：
1. 测试不同加权策略
2. 选择最佳的

预期改进：0.03-0.10pp
